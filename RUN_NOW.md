# Run Your React + Vite App NOW

## Three Simple Steps

### Step 1️⃣ - Install Packages (2 minutes)
```bash
npm install
```
This installs all dependencies including React Router.

### Step 2️⃣ - Copy Images (1 minute)
```bash
# Copy images from original project to React app
mkdir -p src/assets/img
cp -r adult-ai/img/* src/assets/img/
```

Or do it manually:
1. Open `adult-ai` folder
2. Copy the entire `img` folder
3. Paste into `src/assets/`

### Step 3️⃣ - Start Development Server (30 seconds)
```bash
npm run dev
```

You'll see:
```
Local:   http://localhost:5173
```

Click the link or open in browser!
