================================================================================
                         TROUBLESHOOTING TIPS
================================================================================

Images not showing:
  → Copy images: cp -r adult-ai/img/* src/assets/img/
  → Check image paths in components

Port already in use:
  → Edit vite.config.js port setting
  → Or kill process on that port

Styling issues:
  → Verify CSS files are imported in main.jsx
  → Check Bootstrap CDN link in index.html
  → Review component-specific CSS

Navigation not working:
  → Check React Router version (should be 6.20.0)
  → Verify route paths in main.jsx
  → Clear browser cache

Dependencies missing:
  → Run: npm install
  → Check package.json for versions
  → Run: npm install --save-dev @vitejs/plugin-react
