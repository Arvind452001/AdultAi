================================================================================
                          HOW ROUTING WORKS
================================================================================

User Flow:
──────────
1. User visits: http://localhost:5173/
2. BrowserRouter (main.jsx) intercepts the route
3. Router matches "/" path in App.jsx
4. Route finds matching path and renders <HomePage />
5. HomePage component displays
6. User sees content without page reload

User Clicks Link:
─────────────────
1. User clicks <Link to="/login">Login</Link>
2. React Router prevents default browser behavior
3. URL changes to /login (no page reload)
4. Router matches "/login" path
5. Route renders <LoginPage />
6. Smooth transition, URL history updated

Programmatic Navigation:
────────────────────────
1. User submits form with phone number
2. handleLogin() called
3. navigate('/otp-verify', { state: { phone } }) executed
4. URL changes to /otp-verify
5. OTP page receives phone number via location state
6. Automatic redirect after validation
