CRITICAL NOTES
================================================================================

1. ALWAYS use absolute paths starting with "/" for assets:
   CORRECT:   <img src="/img/logos/logo.png" />
   WRONG:     <img src="./img/logos/logo.png" />
   WRONG:     <img src="img/logos/logo.png" />

2. CSS files are already imported in src/styles/index.css
   No need to manually link CSS in components

3. Fonts are loaded through CSS automatically
   Just use Font Awesome classes: <i className="fa fa-icon"></i>

4. Build size includes all assets in public/
   Use only necessary images to minimize bundle size

5. For production: npm run build
   All assets in public/ will be included

================================================================================
TROUBLESHOOTING
================================================================================

Images not showing?
  → Check browser DevTools (F12) Network tab for 404 errors
  → Verify file exists in public/img/
  → Check path is absolute (starts with /)

CSS not applying?
  → Check public/css/ folder exists with both .css files
  → Verify no CSS syntax errors (DevTools > Console)
  → Clear browser cache (Ctrl+Shift+Delete)

Fonts not rendering?
  → Check public/fonts/ folder has all 16 files
  → Verify CSS @font-face declarations are correct
  → Check DevTools for failed font loads

Dev server won't start?
  → Run: npm install
  → Delete node_modules folder and reinstall
  → Check Node.js version (v16+)
